# BusBuddy Bangkok

**ขึ้นรถเมล์กรุงเทพฯ ได้ แม้ไม่เคยขึ้นมาก่อน**  
**Navigate Bangkok buses with confidence — even on your first ride**

[**ทดลองใช้ / Live Demo**](https://maitoweiei.github.io/BusBuddy-Bangkok/) · [**ภาษาไทย**](#-ปัญหาที่ต้องการแก้) · [**English**](#-english)

---

เว็บแอป (PWA) ช่วยวางแผนการเดินทางด้วยรถเมล์และรถไฟฟ้าในกรุงเทพฯ ใช้เส้นทางและตารางเดินรถจริงจากสำนักงานนโยบายและแผนการขนส่งและจราจร (สนข.) และเน้นแก้ปัญหาที่คนขึ้นรถเมล์เจอจริง เช่น ไม่รู้ว่าต้องลงป้ายไหน จำเลขสายใหม่ไม่ได้ กำแพงภาษาของนักท่องเที่ยว และไม่กล้าถามพนักงาน

## ปัญหาที่ต้องการแก้

- รถเมล์หลายคันไม่มีจอหรือเสียงประกาศชื่อป้าย ผู้โดยสารที่ไม่คุ้นทาง ผู้พิการทางสายตา และนักท่องเที่ยวจึงลงผิดป้ายได้ง่าย
- รถเมล์เปลี่ยนเลขสายใหม่ (เช่น 34E เป็น 1-2E) หลายคนยังจำแต่เลขเดิม
- นักท่องเที่ยวและชาวต่างชาติอ่านป้ายหน้ารถหรือสื่อสารกับกระเป๋ารถเมล์ลำบาก
- แอปแผนที่ทั่วไปบอกเส้นทางได้ แต่ไม่ได้ช่วยเรื่องตอนอยู่บนรถ

## ฟีเจอร์หลัก

| ฟีเจอร์ | รายละเอียด |
|---|---|
| **ปลุกก่อนถึงป้ายลง** | ใช้ GPS ของมือถือเทียบกับเส้นทางของสาย เตือนด้วยเสียงพูด (ไทย/อังกฤษ) การสั่น และแถบสีเมื่อเหลืออีก 2 ป้าย เมื่อถึงป้าย และเมื่อเลยป้าย |
| **การ์ดยื่นให้กระเป๋ารถ** | แสดงชื่อป้ายที่จะลงเป็นภาษาไทยตัวใหญ่เต็มจอยื่นให้พนักงานดูแทนการพูด พร้อมคำแปลภาษาอังกฤษกำกับด้านล่างสำหรับนักท่องเที่ยว |
| **รองรับ 2 ภาษา (ไทย / English)** | สลับภาษาได้ทันทีทั้งหน้าจอ ชื่อป้ายและถนนบนแผนที่ 3 มิติ การค้นหา และเสียงพูดแจ้งเตือน |
| **ค้นหาด้วยเลขสายเก่า** | พิมพ์ "34E" แล้วเจอ "1-2E (เดิม 34E)" พิมพ์ไม่ใส่ขีดก็เจอ เช่น `326e` |
| **วางแผนรถเมล์ + BTS/MRT** | เปลี่ยนรถได้ 1 ครั้ง เดินไปต่อรถที่ป้ายหรือสถานีใกล้ ๆ ได้ไม่เกิน 400 ม. เรียงทางเลือกตามเวลา จำนวนครั้งที่เปลี่ยนรถ ระยะเดิน หรือความแน่น และแสดงเวลาถึงเป็นช่วง ไม่ใช่ตัวเลขเดียว |
| **แผนที่ที่อ่านง่าย** | ซูมออกเห็นแค่จุดเปลี่ยนรถสำคัญและสถานีรถไฟฟ้า เมื่อเลือกสาย ป้าย หรือแผนการเดินทาง แผนที่จะซ่อนสายอื่นทั้งหมด |
| **ข้อมูลรถ** | บอกว่าเป็นรถแอร์หรือไม่ และรถเข็นขึ้นได้หรือไม่ แยกให้เห็นว่าข้อมูลไหนยืนยันจาก สนข. ข้อมูลไหนเป็นข้อมูลจำลอง |
| **แจ้งเตือนเมื่อรถใกล้ถึงป้าย** | ตั้งให้เตือนเมื่อรถคันที่เลือกเหลืออีก 2, 5 หรือ 10 นาที |

## ข้อมูลไหนจริง ข้อมูลไหนจำลอง

| ข้อมูล | สถานะ |
|---|---|
| เส้นทาง ป้าย สถานี และแนวเส้นทาง | **จริง** จาก สนข. |
| ตารางเดินรถและความถี่ | **จริง** จาก สนข. |
| เลขสายใหม่และเลขสายเดิม | **จริง** จาก สนข. |
| รถแอร์ / รถเข็นขึ้นได้ | **จริงบางส่วน** (เฉพาะเที่ยวที่ สนข. ระบุไว้) |
| ตำแหน่ง GPS ของผู้ใช้ในฟีเจอร์ปลุก | **จริง** |
| ตำแหน่งรถ ความแน่นบนรถ และเวลารถถึงแบบสด | **จำลอง** เพราะข้อมูลตำแหน่งรถเมล์สดยังไม่เปิดให้ใช้ทั่วไป |
| ค่าโดยสาร | **ประมาณการ** บางสายยังไม่มีข้อมูล |

แอปแยกส่วนรับข้อมูลออกจากหน้าจอไว้แล้ว (`TransitDataProvider`) ถ้าได้ข้อมูลรถสดแบบ GTFS-Realtime ในอนาคต ก็เปลี่ยนแค่ส่วนรับข้อมูล ไม่ต้องแก้หน้าจอ

## ขอบเขตข้อมูล

- พื้นที่ใจกลางกรุงเทพฯ ในรัศมีประมาณ 7 กม. รอบสยาม
- 165 เส้นทาง (รถเมล์ BTS และ MRT) · 1,449 ป้ายและสถานี · รถจำลอง 553 คัน

## เทคโนโลยี

React · TypeScript · Vite · Tailwind CSS · MapLibre GL JS (3D) · Leaflet · OpenFreeMap / OpenStreetMap · PWA · lucide-react

ทำงานในเบราว์เซอร์ทั้งหมด ไม่มีเซิร์ฟเวอร์ของตัวเอง ตำแหน่งของผู้ใช้จึงไม่ถูกส่งหรือเก็บไว้ที่ใด

## เริ่มใช้งานในเครื่อง

ต้องมี Node.js 18 ขึ้นไป

```bash
npm install
npm run dev
```

เปิด http://localhost:5173/BusBuddy-Bangkok/

| คำสั่ง / ลิงก์ | ใช้ทำอะไร |
|---|---|
| `npm run build` | สร้างไฟล์สำหรับขึ้นเว็บ (รวม Service Worker สำหรับ PWA) |
| `?data=mock` ต่อท้ายลิงก์ | ใช้ข้อมูลจำลองทั้งหมด พร้อมปุ่มทดสอบสถานการณ์ เช่น รถแน่นหรือเหตุขัดข้อง |

ฟีเจอร์ปลุกก่อนถึงป้ายลงต้องเปิดผ่าน https (เช่น GitHub Pages) หรือ localhost เพราะเบราว์เซอร์ไม่ให้ใช้ GPS ผ่าน http  
ถ้าจะทดสอบในคอม ให้กด F12 → More tools → Sensors แล้วตั้งพิกัดเองได้

## อัปเดตข้อมูลจาก สนข.

ดาวน์โหลดไฟล์ GTFS ใหม่จาก [Namtang Open Data (สนข.)](https://namtang-api.otp.go.th/opendata)  
แล้วรัน `node scripts/import-namtang.mjs` เพื่อสร้าง `src/data/namtang.json` ใหม่

## โครงสร้างโปรเจกต์

```text
src/
  domain/      ตรรกะหลัก: วางแผนการเดินทาง ค้นหา เวลาถึง ปลุกก่อนถึงป้าย
  data/        ข้อมูล สนข. ตัวแปลงข้อมูล และข้อมูลจำลอง
  services/    ส่วนรับข้อมูล (เลือกข้อมูลจริงหรือข้อมูลจำลอง)
  sim/         ตัวจำลองตำแหน่งรถ
  components/  หน้าจอ แผนที่ 3D/2D และแผนผังย่อ
  hooks/       จัดการสถานะ GPS เครือข่าย และข้อมูลสด
  lib/         ระบบสลับภาษา (i18n) เสียงพูดแจ้งเตือน (TTS) และตัวจัดรูปแบบ
```

## ข้อจำกัด

- ตำแหน่งรถ ความแน่น และเวลารถถึงแบบสดยังเป็นข้อมูลจำลอง
- การปลุกต้องเปิดหน้าจอค้างไว้ (แอปขอ Wake Lock ให้อัตโนมัติ แต่เว็บแอปยังใช้ GPS ตอนกดล็อกจอไม่ได้)
- เปลี่ยนรถได้ไม่เกิน 1 ครั้ง ยังไม่รวมเรือและรถไฟฟ้านอกพื้นที่

## แผนพัฒนาต่อ

- หน้าภาษาอังกฤษสำหรับนักท่องเที่ยว
- ติดตั้งเป็นแอปบนมือถือได้ (PWA) และดูตารางได้แม้ไม่มีเน็ต
- แผนสำหรับผู้ใช้รถเข็น และโหมดเลี่ยงการเดินตอนอากาศร้อนหรือฝนตก
- เชื่อมข้อมูลตำแหน่งรถสด (GTFS-Realtime) เมื่อมีข้อมูลเปิด
